# Global Project Scope

- Treat this project as research/experimental by default.
- Adversarial review should focus on scientific correctness: data semantics,
  representations, model architecture, conditioning paths, objectives,
  training, sampling, metrics, evaluation protocols, reproducibility, and
  distributed/resume consistency.
- Do not turn production-only concerns such as artifact tamper resistance,
  signatures, immutable root seals, hostile manifest rewriting, or supply-chain
  hardening into implementation work or gate blockers.
- Apply production-grade security and anti-tamper review only when the project
  owner explicitly states that the current task is a production environment.
